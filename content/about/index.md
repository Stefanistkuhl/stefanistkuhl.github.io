I'm Veya Fürst.

I work on networking, systems, backend infrastructure, and developer tooling. Go is my main language, with Python and C for automation and lower-level work. I also use Svelte and Astro when a project needs a web interface.

My current focus is [tethux](https://github.com/tethux/tethux), an in-development network-emulation toolkit for programmable Ethernet topologies across containers, virtual machines, and physical hosts. I also maintain a collection of [networking and security work](/networking-security/) covering packet analysis, Linux networking and hardening, wireless security, and infrastructure.

This site is where I put project writeups, technical notes, experiments, and school/42 documentation.

Most of my code is on [GitHub](https://github.com/0xveya).
